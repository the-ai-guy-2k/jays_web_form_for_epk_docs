# ACR-018 — Narrow mobile album cover clip repair

**Date:** 2026-10-08  
**ACI:** ACI-CAE-JGB-WEB-EPK-V1-MOBILE-COVER-FIX-018  
**Starting SHA:** `453057fba2c80ebc92d2088afcf8a066e6891889`

At ~390px the hero grid item used the cover PNG’s intrinsic min-content width (1254px). Combined with `body { overflow-x: hidden }`, the right side of the approved square was clipped.

**Correction:** `min-width: 0` on `.hero-inner`, `.hero-copy`, and `.hero-cover` so the hero grid can shrink below the PNG’s intrinsic size. `.hero-cover` uses `max-width: min(460px, 100%)`. `.cover-img` uses `width: 100%`, `max-width: 100%`, `height: auto`.

Artwork `public/epk/img/still-chasing-the-sundown-cover.png` was not modified.
